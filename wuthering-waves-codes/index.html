How to redeem Wuthering Waves codes

1. Reach Union Level 2

The redemption option becomes available after the early account progression requirement.

2. Open Settings

Launch the game, open the main menu, and select the Settings icon in the lower-right area.

3. Open Other Settings

Choose Other Settings, then find the Redemption Code option under the Account section.

4. Enter and collect

Paste the code, confirm it, then open the in-game mailbox to collect the rewards.

No web redemption page: WuWa codes are redeemed inside the game. Avoid unofficial pages that ask for account credentials.

Why a WuWa code may not work

  • The code expired after a livestream or limited event.
  • The code was already used on this account.
  • A letter, number, or capitalization does not match.
  • The account has not reached Union Level 2.
  • The reward mail has not appeared yet; reopen the mailbox or restart the game.

When new codes usually appear

New codes most often arrive during version preview livestreams, anniversary events, platform launches, or special collaborations. Livestream codes usually expire much faster than permanent gift codes.

Wuthering Waves codes FAQ

What Wuthering Waves codes are active in September 2026?

WUTHERINGGIFT is the only code cross-checked as active on September 18, 2026. Redeem it promptly because code status can change.

Where do I redeem WuWa codes?

Use the in-game path: Settings → Other Settings → Redemption Code. There is no separate official web redemption page.

Can I redeem the same code twice?

No. A redemption code can normally be claimed once per account.

Where do the rewards go?

Successful rewards are delivered through the in-game mailbox. If they do not appear immediately, reopen the mailbox or restart the game.
